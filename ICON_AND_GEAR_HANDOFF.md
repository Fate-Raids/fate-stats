# Item icons and character gear

See `README.md` for active item/icon behavior and `PLUSONE_MASTER_EXPORTER_HANDOFF.md` for the optional addon changes. The website's item registry looks up names/icons/rarities centrally. Absent a verified texture name, the code attempts Wowhead's officially documented tooltip iconization and uses a clearly generic fallback if unavailable. This release does not promise precise icon artwork for all Forever items without further source data. The center armor illustration is original decorative artwork, not a real 3D reconstruction.
